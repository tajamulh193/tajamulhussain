Verification against textbook formulas

Each time the page loads, the solver is run on standard cases and compared with closed-form results. All must agree within 0.1%.

Method

Reactions come from equilibrium (ΣF = 0, ΣM = 0). Shear and moment are summed exactly at 801 points along the beam. Deflection is found by integrating M / EI twice with the trapezoidal rule, then applying the boundary conditions: δ(0) = δ(L) = 0 for a simply supported beam, or δ(0) = θ(0) = 0 for a cantilever fixed at the left. Bending stress is σ = M·y / I; average shear stress is V / Aweb for I-sections and 1.5 V / A for solid rectangles.
