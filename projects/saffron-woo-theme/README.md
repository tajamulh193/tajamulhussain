# Saffron: WooCommerce block theme (sample)

A Full Site Editing theme for small fashion and craft shops, built for WordPress 6.4+ and WooCommerce.

**[Open the interactive preview](https://tajamulh193.github.io/tajamulhussain/projects/saffron-woo-theme/preview/)** · **[Download saffron.zip](saffron.zip)**

## What's inside

| Part | Details |
|---|---|
| `theme.json` | Colour palette, fluid type scale, spacing and button styles, all editable in Appearance > Editor > Styles |
| `templates/` | Home, shop archive, single product, posts, pages and 404, built from blocks |
| `parts/` | Header with mini cart and account icon; footer with newsletter pattern |
| `patterns/` | Shop hero, category tiles, newsletter sign-up (translation-ready, escaped output) |
| `functions.php` | WooCommerce gallery support, block styles, 4-column shop grid, free-shipping message in the mini cart |

## Checks

- Every PHP file passes `php -l` on PHP 8.3, and `theme.json` is valid JSON against the v3 schema layout.
- The preview page reproduces the shop experience (filters, sorting, quick view, cart drawer, free-shipping bar) as static HTML, because GitHub Pages cannot run WordPress.
- It has not yet been installed on a live WordPress site.

The shop and products are fictional.
