A WooCommerce-ready block theme for small fashion and craft shops.

== Description ==
Saffron is a Full Site Editing theme. Colours, fonts and spacing live in theme.json,
so a shop owner can restyle the whole site from Appearance > Editor > Styles.

Includes:
* Templates for the home page, shop archive, single product, posts, pages and 404.
* Patterns: shop hero, category tiles and newsletter sign-up.
* Block styles: "Card" for groups and "Outline" for buttons.
* WooCommerce gallery zoom, lightbox and slider support.
* A free-shipping progress message in the mini cart (filter: saffron_free_shipping_threshold).
